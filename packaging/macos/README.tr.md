# Numtilo 0.2.1 — macOS

ZIP'in tamamını çıkarın, ardından Finder'da **Numtilo.app** dosyasına çift tıklayın.
Oynamak için terminal, VS Code, CMake veya Homebrew gerekmez.

Bu paket **Apple Silicon (ARM64), macOS 26.2 ve üzerini** hedefler.
Intel, Windows veya Linux uygulaması içermez. Ad hoc imzalıdır ve noter onaylı
değildir; macOS güvenlik kontrolleri internetten indirilen kopyayı engelleyebilir.

## Oynama

- Bir oyuncu adı yazıp Enter ile başlayın.
- Yön tuşlarıyla eşit karoları kaydırıp birleştirin; 2048'e ulaşın.
- Oyun sırasında veya Oyun Bitti ekranında N yeni tur başlatır; Esc menüye döner.
- Ses kontrolüyle efektleri kapatıp açabilirsiniz.
- Tab / Shift+Tab ile kontrol odağını taşıyın; Enter / Space ile etkinleştirin.
- Skor tablosunda Esc / Q / Backspace menüye döner.
- Normal çıkış için pencereyi kapatın veya Command-Q kullanın.

Skorlar ve ses tercihi yerel olarak kaydedilir. Aktif oyun tahtası kaydedilmez.
