# Numtilo 0.2.1 — macOS

Extract the entire ZIP, then double-click **Numtilo.app** in Finder.
No terminal, VS Code, CMake or Homebrew is required to play.

This package targets **Apple Silicon (ARM64), macOS 26.2 or later**.
It does not include an Intel, Windows or Linux application. It is ad hoc signed,
not notarized; macOS security checks may block a downloaded copy.

## Playing

- Enter a player name and press Enter to start.
- Use the arrow keys to slide and merge matching tiles; reach 2048.
- Press N for a new round during play or after Game Over; Esc returns to the menu.
- Use the sound control to turn effects off or on.
- Use Tab / Shift+Tab to move control focus and Enter / Space to activate it.
- On the leaderboard, Esc / Q / Backspace returns to the menu.
- Close the window or press Command-Q to quit normally.

Scores and the sound preference are saved locally. The active board is not saved.
